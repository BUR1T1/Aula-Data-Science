# Aula de Data Science

Materiais de aula e kit de estudo para a prova de Ciência de Dados.

- `Kit_Socorro_Prova_Ciencia_de_Dados/`: exemplos Python, notebook prático, dados e textos de revisão.
- `Dolucas/`: materiais de aula e guia de consulta.
- `Guia_Pratico_Prova_Ciencia_de_Dados.pdf`: guia prático para a prova.

## Executar o notebook

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r Kit_Socorro_Prova_Ciencia_de_Dados/requirements.txt
cd Kit_Socorro_Prova_Ciencia_de_Dados
jupyter notebook notebooks/Guia_Pratico_Completo.ipynb
```

O arquivo `codigos/07_template_resposta_prova.py` é um modelo para adaptar ao enunciado e requer definir o DataFrame e os nomes das colunas antes de executar.
