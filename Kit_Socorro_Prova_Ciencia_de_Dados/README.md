# Kit de Socorro - Prova de Ciência de Dados

Este pacote foi montado a partir dos materiais enviados nas aulas e notebooks.

## Estrutura

- `textos/`: explicações do básico ao mais avançado.
- `codigos/`: exemplos Python prontos para estudar e adaptar.
- `notebooks/`: notebook prático com células executáveis.
- `dados/`: base sintética simples para testar os códigos.
- `fontes_originais/`: cópias dos arquivos enviados.
- `Guia_Socorro_Prova_Ciencia_de_Dados.pdf`: versão resumida em PDF.
- `requirements.txt`: bibliotecas usadas.

## Ordem sugerida para estudar

1. Pandas e leitura de dados
2. Estatística descritiva
3. Quartis, IQR e outliers
4. Visualização
5. Teste A/B e p-valor
6. Correlação, Pearson e Spearman
7. Regressão linear
8. R² e RMSE
9. LGPD e governança
10. Projeto integrador

## Regra de emergência

Quando receber uma questão prática:

1. Leia o enunciado e identifique o tipo de problema.
2. Confira os nomes das colunas.
3. Faça uma inspeção rápida com `head()`, `info()` e `describe()`.
4. Limpe ou filtre se necessário.
5. Calcule a métrica.
6. Faça o gráfico adequado.
7. Interprete em palavras.
8. Só depois conclua.
